## 问题：长时间运行再重启后 IsAssignableFrom 崩溃

### 崩溃栈
```
Class::IsAssignableFrom (Class.cpp:780)
StackTrace_GetFullNameForStackTrace
StackTrace_AddFrames
StackTrace_ToString
Exception_ToString
```

### 根因
`IsAssignableFrom` 的 `else` 分支遍历 `oklass` 的 parent 链，访问 `iter->implementedInterfaces[i]`，但没有检查 `implementedInterfaces` 是否为 NULL。

泛型实例类 `ProgressResult<T>` 在 reload 后：
- Pass 2 置空了 `implementedInterfaces`
- 泛型 Pass 3 调用了 `Class::Init`，但 `InitLocked` 可能在 `SetupInterfacesLocked` 之前抛出异常（通过 `longjmp`），导致 `implementedInterfaces` 保持 NULL
- 后续 `Class::Init` 调用时 `init_pending=1`，`InitLocked` 直接返回 true，但 `implementedInterfaces` 仍为 NULL

### 修复
在 `IsAssignableFrom` 的两个分支（`klass->generic_class != NULL` 和 `else`）中，对 `implementedInterfaces` 和 `interfaceOffsets` 添加 NULL 检查。同时在遍历 parent 链时，如果 `iter->interfaces_count > 0 && implementedInterfaces == NULL`，先调用 `Class::Init(iter)` 触发懒加载。

## BackpackTabType ArgumentException 修复（2026-08-05）

### 根因
`s_MethodMap`（`AppendOnlyGCHashMap`）缓存了 `Il2CppReflectionMethod*`（C# `MethodInfo` 对象），用 `MethodInfo*` 作为 key。reload 后 `MethodInfo*` 被复用，`s_MethodMap` 命中旧缓存，返回旧 `Il2CppReflectionMethod*`。旧 `Il2CppReflectionMethod*` 的 `method` 字段指向旧膨胀 `MethodInfo*`，后者的 `parameters` 是旧膨胀的 `Il2CppType*`（`typeHandle` 指向旧 `typeDef`）。

`ValidateOneArgument` 比较参数的 `Type`（新）和方法参数定义的 `Type`（旧 `ParameterInfo` 缓存），`Type ==` 返回 false → `ArgumentException`。

### 修复
1. `AppendOnlyGCHashMap` 添加 `ForEachValue` 方法，支持遍历所有存储的值
2. `Reflection::FixupMethodMapForReload` 遍历 `s_MethodMap`，对每个膨胀泛型方法的 `Il2CppReflectionMethod*`，通过 `GenericMethod::GetMethod(gmethod)` 重新解析，获取新膨胀 `MethodInfo*`，更新 `method` 字段
   - 条件：`method->is_inflated && method->genericMethod`（不是 `is_generic`，膨胀后 `is_generic=false`）
3. `Reflection::ClearParametersMapForReload` 清除 `s_ParametersMap`，确保 `GetParameters()` 重新创建 `ParameterInfo[]`
4. 在 `RestoreReusedClasses` 中调用以上两个函数
