# 2026-07-30 工作日志

## 问题：rehash 后 GetGenericClass: NEW 和 ParentMismatch 仍然出现 (log 6)

### 根因
Pass 1 更新 `klass->byval_arg.data.typeHandle` 指向新 `Il2CppTypeDefinition`，但 `Il2CppGenericClass->type` 和 `Il2CppGenericInst->type_argv[i]` 可能指向旧 image 类型表中的 `Il2CppType` 对象（其 `data.typeHandle` 未被 Pass 1 更新）。

rehash 仅清除并重新插入条目以重算 hash，但用的仍是旧 `typeHandle` 值。新 lookup（从 `&klass->byval_arg`）用新 `typeHandle` → hash 不匹配 → 创建重复条目 → `ParentMismatch`。

### hash/compare 链路
- `Il2CppTypeHash::Hash` 对 CLASS/VALUETYPE 用 `data.typeHandle` 指针值
- `Il2CppGenericInstHash::Hash` 调 `Il2CppTypeHash::Hash(type_argv[i])`
- `Il2CppGenericClassHash::Hash` 调 `Il2CppTypeHash::Hash(item->type)` + `Il2CppGenericContextHash::Hash(&item->context)`
- `Il2CppGenericContextHash::Hash` 调 `Il2CppGenericInstHash::Hash(context->class_inst)`
- `Il2CppGenericClassCompare::Compare` 调 `Il2CppTypeEqualityComparer::AreEqual(gc1->type, gc2->type)` + `Il2CppGenericInstCompare::Compare(class_inst)`
- `Il2CppTypeEqualityComparer::AreEqual` 对 CLASS/VALUETYPE 比较 `data.typeHandle`

### 修复
在三个 rehash 函数中，遍历条目时更新陈旧指针：

1. **`RehashGenericInstSet`**（vm/MetadataCache.cpp）：对每个 `Il2CppGenericInst`，遍历 `type_argv[i]`，若 CLASS/VALUETYPE 且 `klass->byval_arg.data.typeHandle != t->data.typeHandle`，则更新 `type_argv[i] = &klass->byval_arg`
2. **`RehashGenericClassSet`**（metadata/GenericMetadata.cpp）：对每个 `Il2CppGenericClass`，若 `gclass->type` 是 CLASS/VALUETYPE 且类被复用，更新 `gclass->type = &klass->byval_arg`
3. **`RehashGenericTypeSet`**（vm/GenericClass.cpp）：同上

查找类用 `MetadataCache::GetTypeInfoFromType(defType)` → `GlobalMetadata::GetTypeInfoFromType` → `GetTypeInfoFromHandle(typeHandle)` → `GetIndexForTypeDefinitionInternal` → `GetTypeInfoFromTypeDefinitionIndex`。即使 `typeHandle` 是旧值，`IsInterpreterType` 仍能识别，`GetTypeEncodeIndex` 仍能返回编码索引，最终返回被复用的 `Il2CppClass*`（其 `byval_arg.data.typeHandle` 已是新值）。

### 修改的文件
- `vm/MetadataCache.cpp` — `RehashGenericInstSet` 增加 `type_argv[i]` 指针更新
- `metadata/GenericMetadata.cpp` — `RehashGenericClassSet` 增加 `gclass->type` 指针更新
- `vm/GenericClass.cpp` — `RehashGenericTypeSet` 增加 `gclass->type` 指针更新 + 诊断日志

### 状态
**已修复**（用户确认）。rehash 时不仅重算 hash，还更新陈旧的 `Il2CppType*` 指针指向 `&klass->byval_arg`，使旧条目的 hash/compare 与新 lookup 一致，消除 `GetGenericClass: NEW` 重复创建和 `ParentMismatch`。
