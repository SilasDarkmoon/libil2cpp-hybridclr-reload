## Il2CppClass vtable 改为固定长度 128
- 需求：将变长结构 Il2CppClass 改为固定长度，vtable 固定为 128 槽；元数据加载时 vtable 超过 128 则舍弃多余元素并打印错误，vtable_count 截断到 128 以避免后续崩溃。
- 修改点：
  - `il2cpp-class-internals.h`：新增 `#define IL2CPP_MAX_VTABLE_SLOT_COUNT 128`，`vtable[IL2CPP_ZERO_LEN_ARRAY]` 改为 `vtable[IL2CPP_MAX_VTABLE_SLOT_COUNT]`。
  - `vm/Class.h` / `vm/Class.cpp`：新增静态方法 `Class::ClampVTableSlotCount(uint32_t, namespaze, name)`，超限时用 `il2cpp::utils::Logging::Write` 打印错误并返回 128。Class.cpp 增加 `#include "utils/Logging.h"`。
  - 变长分配改为固定 `sizeof(Il2CppClass)`：`vm/GlobalMetadata.cpp` FromTypeDefinition、`vm/GenericClass.cpp` GetClass、`metadata/ArrayMetadata.cpp` 数组类创建。
  - vtable_count 赋值处应用截断：GlobalMetadata.cpp:1659、Class.cpp 泛型实例 SetupVTable（并把填充循环边界改为 `i < klass->vtable_count`）、ArrayMetadata.cpp:541。
  - `ArrayMetadata.cpp` `PopulateArrayGenericMethods` 写 `klass->vtable[vtableIndex]` 处加 `if (vtableIndex >= IL2CPP_MAX_VTABLE_SLOT_COUNT) continue;` 防越界。
- 说明：InterpreterImage 的解释器类型也走 GlobalMetadata::FromTypeDefinition 分配，故一并被截断覆盖。lint 全部通过。

## Il2CppClass vtable 改为「固定布局 + 超阈值变量布局」混合方案
- 需求：`IL2CPP_MAX_VTABLE_SLOT_COUNT` 改回 128；新增 `IL2CPP_PRESERVED_VTABLE_SLOT_COUNT = 16`；当 `vtable_count + 16 > 128`（即 vtable_count > 112）时走**原变长 struct**逻辑，分配槽数 = `vtable_count + 16`，不再丢弃/截断；给 Il2CppClass 增加 `vtable_allocated_count` 字段记录实际分配的 vtable 槽数。
- 布局规则：`vtable[IL2CPP_MAX_VTABLE_SLOT_COUNT]` 仍为内联固定 128 槽（结构体末尾）。固定布局：分配 `sizeof(Il2CppClass)`，`vtable_allocated_count = 128`，`vtable_count` 不截断。变量布局：分配 `sizeof(Il2CppClass) + (vtable_count + 16 - 128) * sizeof(VirtualInvokeData)`，`vtable_allocated_count = vtable_count + 16`。
- 实现：`ClampVTableSlotCount` 重命名为 `Class::ComputeVTableAllocatedSlotCount(uint32_t vtableCount, namespaze, name)`，返回分配槽数；变量布局时仍向控制台 + `vtable_overflow.log`（UNITY_TEMPORARY_CACHE_PATH 或 `log/`）写 "vtable variable-layout" 日志。
- 分配点（均需先算 vtableAllocated 再分配，并设 `vtable_count` 与 `vtable_allocated_count`）：`vm/GlobalMetadata.cpp` FromTypeDefinition、`vm/GenericClass.cpp` CreateClass（用 `definition->vtable_count`，泛型实例后续 SetupVTable 仅同步 vtable_count 不再 clamp）、`metadata/ArrayMetadata.cpp` 数组类（用 slots）。另：`vm/Class.cpp` 泛型参数类(:283) 与指针类(:1921) 这两个特殊分配补设 `vtable_count=0; vtable_allocated_count=128`（calloc 会清零，必须显式赋值否则守卫误判）。
- `ArrayMetadata.cpp` `PopulateArrayGenericMethods` 原先 `if (vtableIndex >= IL2CPP_MAX_VTABLE_SLOT_COUNT) continue;` 改为 `if (vtableIndex >= klass->vtable_allocated_count) continue;`。
- 说明：所有 vtable 写/读都按 `vtable_count` 或 `vtable_allocated_count` 边界，变量布局下 `vtable_count+16` 覆盖了数组 interfaceOffset 越界槽（这正是 PRESERVED=16 的用途）。lint 全部通过。

## vtable 常量再次调整（实际调参）
- 将 `IL2CPP_MAX_VTABLE_SLOT_COUNT` 由 128 改为 **256**，`IL2CPP_PRESERVED_VTABLE_SLOT_COUNT` 由 16 改为 **32**（仅改 `il2cpp-class-internals.h` 两处宏）。
- 其余分配/守卫逻辑均引用这两个宏，未硬编码数值，已自动采用新值：变量布局阈值变为 `vtable_count + 32 > 256`（即 vtable_count > 224），变量布局分配槽数 = `vtable_count + 32`。

## vtable 溢出日志增加时间戳（UTC，无毫秒）
- `vm/Class.cpp` `ComputeVTableAllocatedSlotCount`：新增 `#include <ctime>`；用 `std::time(NULL)` 取当前时间，标准 `std::gmtime` 转 UTC tm（跨平台：`gmtime` 在所有平台可用，不用 `gmtime_s`/`gmtime_r` 的平台分支），`strftime` 格式化为 `%Y-%m-%d %H:%M:%S`。MSVC 对 `gmtime` 有弃用告警，用 `#ifdef _MSC_VER` 局部 `#pragma warning(disable:4996)` 关闭（GCC/Clang 忽略该 pragma，对 iOS/Android 无副作用）。时间戳 `[YYYY-MM-DD HH:MM:SS]`（UTC）同时加到控制台（`Logging::Write`）与文件日志（`vtable_overflow.log`）。**跨平台约束：此日志代码需上 iOS/Android，禁止出现仅 Windows 才编译的功能性分支（`#ifdef _WIN32` 行为级分支不行），仅允许编译器告警抑制类 pragma。** lint 通过。

## 支持重新加载同名程序集（hybridclr Assembly::Create）
- 需求：占位程序集(PlaceHolder)已加载过（`ass->token` 非 0）时不再抛 "reloading placeholder assembly is not supported!"，改走普通新建逻辑创建全新 Il2CppAssembly/Il2CppImage，并把各缓存中的旧程序集移除/替换。
- 改动：
  - `vm/Assembly.h/.cpp`：新增 `Assembly::Unregister(const Il2CppAssembly*)` — 加 s_assemblyLock，从 `s_Assemblies` erase 并 `++s_assemblyVersion`（快照 copy-on-write 机制自动重建）。
  - `vm/MetadataCache.h/.cpp`：新增 `UnregisterInterpreterAssembly(const Il2CppAssembly*)`（加 g_MetadataLock（可重入 ReentrantLock），从 `s_cliAssemblies` erase，再调 `vm::Assembly::Unregister`）与 `GetInterpreterAssemblyByName(const char*)`（逆序查 `s_cliAssemblies`，大小写不敏感比较 aname.name/image->name，返回最近注册的同名解释器程序集）。
  - `hybridclr/metadata/Assembly.cpp`：
    - 新增 `ReplacePlaceHolderAssembly(old, new)`（`#if ENABLE_PLACEHOLDER_DLL` 内替换 `s_placeHolderAssembies` 条目，else 空实现）——保证占位列表始终指向最新一次注册的同名程序集，支持反复重载。
    - `Create` 逻辑：占位且 token==0 → 原复用路径；否则（普通加载或重载）新建 ass/image2，重载时确定 `oldAss`（占位命中即 placeHolderAss；非占位则用 `GetInterpreterAssemblyByName(nameNoExt)` 查旧的），在 `InitRuntimeMetadatas()` 之后、`RegisterInterpreterAssembly(ass)` 之前执行 `UnregisterInterpreterAssembly(oldAss)` + `ReplacePlaceHolderAssembly(oldAss, ass)`。
    - 旧的 Il2CppAssembly/Il2CppImage 及元数据有意不释放（可能仍被已创建类型/方法引用，泄漏换安全）。
- lint 全部通过。非占位的同名解释器程序集重复加载也会走同样的替换逻辑（通用化）。
