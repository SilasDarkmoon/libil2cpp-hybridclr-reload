## PropertyInfo + EventInfo Adapter 实施完成（lint 全净，待构建验证）
- **背景**：MethodInfo（API 层收敛版）用户测试通过后开始。预勘结论：PropertyInfo 7 个 il2cpp-api（2 出 5 入）+ EventInfo 1 个（class_get_events）+ mono-api 5 处 + 1 处直解引用；**icalls 零触点**（RuntimePropertyInfo/EventInfo 全直调 vm::，比 MethodInfo 干净）；debugger 目录无 property 函数。
- **改动（6 文件，标准范式六步）**：
  1. api-types.h：PropertyInfoAdapter/EventInfoAdapter opaque typedef。
  2. adapters.h/.cpp：`PropertyInfoAdapter{const PropertyInfo* real}`、`EventInfoAdapter{const EventInfo* real}` + WrapProperty/UnwrapProperty/RemapPropertyReal、WrapEvent/UnwrapEvent/RemapEventReal（Unwrap 出口 const_cast 交可变指针，同 FieldInfo 范式）。
  3. api-functions.h：8 签名（class_get_events/class_get_properties/class_get_property_from_name 返回值 + 5 个 property_get_* 入参）。
  4. api.cpp：8 处实现；property_get_get/set_method 是"unwrap property → vm 取 MethodInfo → wrap method"的链式转换（跨 adapter 类型协作的首例）。
  5. mono-api.cpp：6 处——mono_class_get_properties(wrap)、mono_property_get_name/parent(unwrap)、mono_property_get_get/set_method(unwrap+wrap method)、mono_custom_attrs_from_property_checked(:1837 直解引用 ->token 修复)。
- **验证**：lint 0 诊断；全库调用方排查=仅 api.cpp 定义本身，无内部调用者（icalls 直调 vm:: 天然无触点）。
- **编译错误修复（用户构建报 C2664）**：vm::Class::GetEvents/GetProperties 返回 const 指针，WrapProperty/WrapEvent 入参原为非 const → 4 处调用编译失败。修复=Wrap 入参统一 const（模板 Wrap 本就收 const RealT*）。**教训：Wrap 入参一律 const RealT*（vm getter 多返回 const）；可变需求只在 Unwrap 出口 const_cast**——此规则并入六步范式。
- **语义注记**：Property/Event 与 FieldInfo 同构——嵌入 klass->properties/events 数组按值分配，RemapReal 热重载配对须按 (parent 类, 成员名)。
- **路线图状态**：Image✓ Assembly✓ FieldInfo✓ MethodInfo✓(API 层收敛版) Property✓ Event✓ → 剩 Il2CppClass + Il2CppType 联动（内容键机制，触点 100+，需先出方案讨论再动手——用户约束）。
