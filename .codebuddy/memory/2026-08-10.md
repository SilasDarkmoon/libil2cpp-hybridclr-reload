# 2026-08-10 工作日志

## NRE 排查：静态字段被重载清零 + 精确定位日志
- 现象：重载后多处 NullReferenceException（EntranceWindow.OnCreate 解释器代码、TMP_SubMeshUI.UpdateMaterial AOT），用户不知哪个变量为 null。
- **根因**：`RestoreReusedClasses` Pass 2（InterpreterImage.cpp）与 `RestoreCachedGenericClassesPass2`（GenericClass.cpp）**无条件把 `klass->static_fields = nullptr`** → 所有复用类/泛型实例的静态字段在重载后清零。非 cctor 赋值的静态状态（单例 `_instance`、运行时缓存）全部变 null → NRE。
- **修复（静态状态保留）**：静态布局不变时保留 `static_fields` 存储与 cctor 状态（`cctor_started`/`cctor_finished_or_no_cctor`），布局变化时维持原重置行为。
  - 非泛型：Pass 1 用 `oldStaticFieldsSizes` 数组先存旧 `static_fields_size` 再覆盖，Pass 2 比较旧==新则保留。
  - 泛型实例：比较实例的（旧）`static_fields_size` 与定义的（新）`static_fields_size`。
- **NRE 定位日志**：`Interpreter_Execute.cpp` 的 `catch (Il2CppExceptionWrapper)` 块中，NRE 时打印 `[ReloadDiag] NRE at <命名空间>.<类>::<方法> ipOffset=<转换后指令流偏移> token=0x... image=...`（frame->method + ip - ipBase）。AOT 代码（如 TMP）的 NRE 无此行号能力，但大概率同源于静态清零。
