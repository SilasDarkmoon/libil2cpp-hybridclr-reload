# 2026-08-06 工作日志

## Expression1<T> → Expression<T> InvalidCastException 修复

### 问题
reload 后 `HomeWindow.BindAll()` 中通过 `Expression.Lambda<TDelegate>` 创建表达式树时抛出：
```
System.InvalidCastException: Unable to cast object of type 'Expression1`1' to type 'Expression`1'.
```
`Expression1<T>` 是 `Expression<T>` 的子类（AOT 类型，在 System.Linq.Expressions 中）。cast 应该成功但失败了。

### 根因
`Il2CppGenericClassHash::Hash` 同时依赖 `gclass->type` 和 `gclass->context.class_inst->type_argv[i]`（通过 `Il2CppGenericContextHash` → `Il2CppGenericInstHash` → `Il2CppTypeHash`）。

rehash 函数 `RehashGenericClassSet` 和 `RehashGenericTypeSet` 更新了 `gclass->type` → `&klass->byval_arg`，但**未更新** `gclass->context.class_inst->type_argv`。

执行顺序：
1. Pass 1: 更新 `klass->byval_arg.data.typeHandle`
2. Rehash: 用陈旧 `type_argv` 重算 hash（`type_argv` 还没归一化）
3. Pass 2: 归一化 `type_argv` → `&newKlass->byval_arg`（但不 rehash）
4. Pass 3: lookup 用新 `type_argv` → hash 不匹配 → 创建重复条目

结果：`Expression1<T>->parent` 指向旧 `Expression<T>` 实例，但 cast 目标是新 `Expression<T>` 实例 → `HasParentUnsafe` 失败。

AOT 创建的 `class_inst` 不在 `s_GenericInstSet` 中，所以 `RehashGenericInstSet` 不会更新它的 `type_argv`。

### 修复
在 `RehashGenericClassSet`（GenericMetadata.cpp）和 `RehashGenericTypeSet`（GenericClass.cpp）中增加 `NormalizeGenericInstTypeArgv` 调用，在 rehash 时同时归一化 `gclass->context.class_inst->type_argv`，确保 hash 用归一化后的值计算。

### 文件改动
- `metadata/GenericMetadata.cpp`: 新增 `NormalizeGenericInstTypeArgv` static 函数，在 `RehashGenericClassSet` 中调用
- `vm/GenericClass.cpp`: 新增 `NormalizeGenericInstTypeArgv` static 函数，在 `RehashGenericTypeSet` 中调用
