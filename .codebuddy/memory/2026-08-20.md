## Unity 源码反序列化全链路分析（用户指明方向：问题在 Unity 底层缓存，在 il2cpp 边界加日志）
- **用户约束**：MonoBehaviour 类**必须复用**（复用 Il2CppClass 的初衷就是避免 prefab 脚本 Missing/新旧共存）；不能改 Unity 原生代码，只能读源码+在 il2cpp 边界加日志。
- **缓存键实锤**：`scripting_class_get_hash(klass) = ~klass`（指针取反）→ MonoScriptCache 与 SerializationCache 均按**类指针**键控，复用类同指针共享缓存。
- **反序列化链路**（编辑器 prefab 加载）：
  1. MonoScript  awake → `RebuildFromAwake` → `scripting_class_from_fullname` → `MonoManager::GetMonoClassWithAssemblyName`（**按程序集名首个匹配**选 image）→ `il2cpp_class_from_name(image, ns, name)`。`MonoScript::GetClass()` 返回**缓存的** `m_ScriptCache->klass`。
  2. 组件 native 字段读取 → m_Script PPtr → `SetScript` → `RebuildMonoInstance`：`FindOrCreateMonoScriptCache`（~klass 键）→ scriptType 检查（`scripting_class_is_subclass_of`）→ `scripting_unity_engine_object_new_and_invoke_default_constructor`（= il2cpp_object_new + ctor）。
  3. 字段传输 `TransferScriptingObject(instance, klass, scriptCache)`：`cachedSerializationData==NULL` → `SerializationCache::FetchData(klass)` 构建（`il2cpp_class_get_fields` + 每字段 `field_get_type/class_from_type/field_get_flags/field_get_name` + `ShouldTransferField`）→ `ExecuteSerializationCommands` 直接内存写；嵌套 managed 对象字段经 `scripting_object_new` 创建。
  4. **实例在字段传输时不存在**：YAML 路径 → 数据进 `BackupState`（稍候 RestoreBackup 回填）；**StreamedBinaryRead 路径 → 静默跳过，无 backup 无警告**（`TransferEngineAndMonoInstance` else 分支为空）——完全符合"对象在、方法跑、字段默认值"症状。
- **ShouldTransferField 放行条件**：非 static/const/NotSerialized + 非 Dictionary/委托/自引用 + （public **或 [SerializeField] 或 [SerializeReference] 属性**）。
- **关键纠正**：`s_currVariable` 是 **`[SerializeField] private`**（此前误记 public；attrs=0x1=Private 正确）→ 它的序列化**完全依赖 `il2cpp_field_has_attribute(field, SerializeField)` 返回 true**——复用类若自定义属性解析失败，字段被静默跳过，与 A/B 现象完全吻合。**当前头号嫌疑**。
- 属性解析路径：`Field::HasAttribute` → `Reflection::HasAttribute` → `MetadataCache::GetCustomAttributeDataReader(field->parent->image, field->token)`——复用后 image/token 理论上都是新 image 的，需实证。
- **新增 3 个 il2cpp 边界挂钩**（il2cpp-api.cpp，均按探针类名过滤+去重）：①`il2cpp_class_from_name`——MonoScript 解析用的 image+得到的 klass 指针（检测绑到陈旧/重复类）；②`il2cpp_field_get_flags`——ShouldTransferField 看到的字段标志（注意 PUBLIC=0x6 非 0x1，已修正解码）；③`il2cpp_field_has_attribute`（SerializeField/SerializeReference/FormerlySerializedAs）——私有字段序列化判定结果。

## reload_diag(4).log：反序列化在执行，但根 UIVA 被跳过
- 用户确认：**prefab 按需加载（开窗才加载），无预载**。

- **根因候选（最终）**：**资产加载时根 UIVA 的 managed 实例在字段传输时不存在**（RebuildMonoInstance 失败/未跑——MonoScript ScriptMissing 或顺序问题），其 s_currVariable 数据进了 detached 对象（80 个 VariableArray 之一），实例后来空建。
